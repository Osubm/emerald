# Emerald Hearth POS v3.0

Professional hospitality management system with modern light-mode design.

## Design System
- **Primary**: Emerald Green (#059669)
- **Background**: Soft Slate (#F1F5F9)
- **Surface**: White (#FFFFFF)
- **Typography**: Inter font family

## Quick Start
```bash
npm install
npm run dev
```

- ✅ Dashboard (Desktop + Mobile)
